# DufBros – Website Redesign

Modernes, responsives Website-Konzept für DufBros in Mannheim.

## Dateien
- `index.html`: Startseite und Inhalte
- `styles.css`: responsives Design
- `script.js`: mobile Navigation
- `favicon.svg`: Browser-Icon

Die Seite ist ohne Build-Prozess direkt auf GitHub Pages nutzbar.

## GitHub Pages aktivieren
1. Im Repository **Settings** öffnen.
2. Unter **Pages** bei **Build and deployment** als Source **Deploy from a branch** auswählen.
3. Branch **main** und Ordner **/(root)** wählen und **Save** klicken.
4. Die Vorschau ist anschließend unter https://chokechain.github.io/dufek/ erreichbar.

## Hinweise vor Produktivsetzung
- Die Website ist ein unabhängiger Designentwurf und ersetzt die bisherige Seite nicht automatisch.
- Die Markenillustrationen sind abstrakt gestaltet, keine offiziellen TCG-Markenlogos.
- Die aktuellen Öffnungszeiten, Adresse, Telefonnummer und der Turnierlink wurden aus der bestehenden Website bzw. deren Impressum übernommen.
- Shop, Instagram, Cardmarket und rechtliche Informationen führen derzeit zur bestehenden Website bzw. zu den externen Diensten.
- Bitte Impressums-/Datenschutzlinks und die Nutzungsrechte an der Marke vor einer produktiven Veröffentlichung prüfen.
